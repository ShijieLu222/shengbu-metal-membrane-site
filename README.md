# 上海胜步铁艺膜结构官网

这是一个用于展示膜结构、铁艺楼梯、大门、电动移动门、栏杆围栏等产品案例的企业官网代码库。第一版目标是搭建简约黑白风格的展示型网站，便于客户快速了解业务范围、施工能力和联系方式。

## 技术栈

- React + TypeScript：页面组件和交互逻辑
- Vite：本地开发和生产构建
- Tailwind CSS：响应式样式与黑白视觉系统
- Framer Motion：轻量动效
- lucide-react：线性图标
- ESLint + Prettier：代码规范和格式化

## 本地运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

检查代码规范：

```bash
npm run lint
```

## 目录结构

```txt
src/
  components/      通用组件
  data/            产品、公司、流程等静态数据
  pages/           页面级组件
  styles/          全局样式
  App.tsx          应用入口布局
  main.tsx         React 挂载入口
```

## 开发规范

- 一个功能模块尽量对应一次独立提交，提交前运行 `npm run lint` 和 `npm run build`。
- 组件保持小而清晰，复用组件放在 `src/components`。
- 展示内容统一放在 `src/data`，避免把大量业务文案散落在组件里。
- 图片优先使用真实项目图。临时远程图只作为视觉占位，后续应替换为公司自有案例图。
- 样式优先使用 Tailwind 工具类；复杂样式可以放到 `src/styles/globals.css`。
- 页面文案面向客户，避免出现技术实现说明。

## 第一版模块

- 首页首屏：公司定位、业务关键词和咨询入口
- 产品展示：膜结构车棚、电动车车棚、楼梯、大门、电动移动门、栏杆围栏
- 公司优势：定制测量、加工安装、售后维护
- 服务流程：咨询、测量、设计、报价、生产、安装、售后
- 联系方式：电话、微信、地址等占位信息
